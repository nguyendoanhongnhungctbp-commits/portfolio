# Portfolio

Web portfolio tĩnh (HTML + CSS), không cần cài đặt gì.

## Chạy trong VS Code
1. Mở thư mục này: File > Open Folder > `portfolio`.
2. Cài extension **Live Server** (Ritwick Dey), bấm chuột phải `index.html` > *Open with Live Server*.

## Sửa nội dung
- Chữ, dự án, link: `index.html`
- Màu, font, bố cục: `style.css` (các biến màu nằm ở đầu file)

## Đưa lên mạng
Kéo thả cả thư mục vào https://app.netlify.com/drop hoặc push lên GitHub rồi import vào Vercel.
